# Chai & Paws Calcutta ☕🐾 (ক্যাফে শিফট)
### Calcutta's Student Part-Time Cafe Jobs & Rush-Hour Staffing Platform

Bringing the flexible student cafe work culture popular in the West to **Calcutta / Kolkata**! A true win-win:
- **For Cafe & Restaurant Owners**: Smoothly manage rush hours and peak service shifts with energetic school and college students.
- **For Students**: Earn pocket money between classes with guaranteed fair hourly pay (**minimum ₹100/hr**, can be increased) in flexible 3+ hour shifts.

---

## 🌟 Key Features

### ☕ Cafe Owner Portal (e.g. *Rakib's Cafe*)
- **Owner & Cafe Registration**: Name, email, mobile with auto-attached `+91` 🇮🇳, cafe location (Park Street, Southern Avenue, Salt Lake, Hindustan Park, etc.), and cafe mascot.
- **Dedicated Cafe Tab**: Direct cafe access right from the home screen.
- **Shift Offer Creation**:
  - Select date & start time.
  - **Enforced Minimum 3 Hours Duration**.
  - **Enforced Minimum ₹100/Hour Wage** (with live net pay preview).
  - Perks chips (Free latte, snack, student tip share, certificates).
- **Real-time Applicant Contact**:
  - When a student applies, the shift is locked and owner receives full candidate details.
  - Direct **📞 Call Student (+91)** and **💬 WhatsApp Chat** action links.

### 🎒 Student Attendant Portal
- **Student Profile**: Name, email, mobile with auto `+91`, gender, age, residence address in Kolkata, and school/college name (*e.g. St. Xavier's, Presidency, Jadavpur University*).
- **Live Calcutta Cafe Feed**: Filter shifts by Kolkata areas and minimum hourly wages.
- **Instant Booking & Real-Time Locking**: As soon as a student applies, the listing is **instantly removed from the public listings** across all devices to prevent duplicate bookings.
- **My Bookings Tab**: Track upcoming shifts, cafe addresses, and total pocket money earnings.

### 🔥 Firebase Cloud Integration
- **Firebase Auth**: User accounts for owners and attendants.
- **Cloud Firestore & Realtime Database**: Real-time shift state sync across all clients.
- **Firebase Storage**: Photo uploads for cafe storefronts and student profile/college ID cards.
- **Firebase Analytics**: User activity measurement.

### 📱 Responsive Across All Devices
- **Mobile**: App-style bottom navigation bar, swipeable Kolkata hub pills, and bottom-sheet modals.
- **Tablet**: 2-column adaptive layout.
- **Desktop**: 3-column rich dashboard with celebratory confetti.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/myselfrakib/cafeshift.git
cd cafeshift

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
